## 状态 / Schema 变化

- Knowledge document 必须包含 `documentId`、`sourceType`、`version`、`effectiveAt`、`title`、`content`、`tags`。
- Retriever 返回的 evidence 必须能映射为 ALG-001 `EvidenceItem`。
- Evidence 必须包含知识版本信息；历史审核通过 BE-002 EvidenceSnapshot replay。
- Role Model Policy 按 role 配置 provider/model，不硬编码。
- Policy Guard 永远 deterministic。

## LLM Structured Output Policy

- 所有真实 Agent 输出必须使用 Zod schema parse。
- parse failure 允许有限重试。
- 重试仍失败必须进入 HUMAN_REVIEW / REVIEW_REQUIRED，不得默认 PASS。
- Evidence 不足时必须输出 missingEvidence。
- 不得无依据直接声称“违法”“事实错误”“监管违规”；应表达为 potential compliance risk、unsupported claim、requires verification、insufficient evidence。

## 校验规则

- retrieval topK 必须为正整数。
- evidence score 允许 `null` 或 0~1。
- Role provider 必须来自冻结 provider enum。
- executionMode 必须为 `mock`、`hybrid` 或 `real`。
- LangSmith metadata 不包含 secret、PII 或完整敏感正文。

## 错误处理

- Knowledge source malformed：typed retrieval failure。
- Retriever unavailable：missing evidence / HUMAN_REVIEW。
- Provider timeout：fail closed。
- LLM parse failure：有限重试后 fail closed。
- Tool unavailable：Specialist 标记 missingEvidence，不得 PASS。
